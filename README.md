📋 Meus Protocolos

Aplicação web desenvolvida para organizar, consultar e gerenciar protocolos de atendimento de forma rápida e prática.

Com o Meus Protocolos, é possível cadastrar protocolos, organizá-los por categorias, pesquisar conteúdos e copiar rapidamente um protocolo para utilização durante um atendimento.

💾 Armazenamento dos dados

A aplicação utiliza o LocalStorage do navegador para armazenar os protocolos e categorias.

Os dados são mantidos localmente no dispositivo e navegador utilizados.

⚠️ Importante

Como não existe um banco de dados externo:

Os dados não são sincronizados entre dispositivos.
Os dados não ficam disponíveis automaticamente em outros navegadores.
Os dados podem ser perdidos caso o armazenamento do navegador seja apagado.
▶️ Como executar o projeto
1. Clone o repositório
git clone https://github.com/JedersonYago/Meus-Protocolos.git

2. Acesse a pasta
cd Meus-Protocolos

3. Execute a aplicação

Abra o arquivo index.html no navegador.

Você também pode utilizar o Live Server no Visual Studio Code.

📖 Como utilizar
Criando um protocolo
Clique em Criar protocolo.
Informe o nome do protocolo.
Escolha uma categoria.
Adicione o conteúdo.
Salve o protocolo.
Editando um protocolo
Localize o protocolo desejado.
Clique em Editar.
Faça as alterações.
Salve novamente.
Copiando um protocolo

Utilize o botão Copiar para enviar o conteúdo do protocolo diretamente para a área de transferência.

Gerenciando categorias

As categorias podem ser criadas, editadas e excluídas para manter os protocolos organizados.

🎯 Objetivo do projeto

O projeto foi criado para facilitar o acesso a protocolos e textos utilizados com frequência durante atendimentos.

A ideia é tornar a consulta mais rápida e organizada, evitando a necessidade de procurar informações em diferentes arquivos ou documentos.
